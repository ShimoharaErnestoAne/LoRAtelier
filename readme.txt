LoRAtelier（ローカル LoRA 制作ツール）
================================================================

キャラクター LoRA とスタイル LoRA を、自分の PC の中だけで作るためのツールです。
画像を入れると自動で確認と説明文づけが行われ、必要なところだけ直して学習を開始できます。
学習後は、LoRA なし・途中の保存版・強さを並べた比較画像を見て選び、書き出せます。
学習には既存の sd-scripts、比較画像の生成には ComfyUI をそのまま使っています。


■ 必須スペック
----------------------------------------------------------------
OS        : Windows 10 / 11（64bit）
GPU       : NVIDIA の GPU で、VRAM 10GB 以上のもの（GeForce RTX 20 シリーズ以降）
            GPU ドライバーは 570 以降が必要です（CUDA 12.8 を使います）。
メモリ    : 32GB 以上
            SDXL 系の学習中は、学習処理だけで約 15GB を使います。
ディスク  : インストール先のドライブに約 40GB の空き
            （実行環境 約 25GB ＋ ベースモデル 1 つあたり 約 7GB ＋ 学習結果）
            C ドライブ（ユーザーフォルダー）に約 25GB の空き
            （素材解析用の AI モデル 約 15GB と、セットアップ時のダウンロードの一時保存）
ネット    : 初回セットアップと、AI モデル・ベースモデルの初回ダウンロードのときだけ必要です。
            それ以降は通信なしで動きます。画像を外部に送ることはありません。
その他    : Python と Git は入っていなくても構いません（セットアップが専用のものを用意します）

GPU がない PC でも、素材の取り込みと編集まではできます。学習は NVIDIA の GPU が必要で、
CPU での学習に切り替えることはしません。
VRAM が 10GB 未満の場合は、学習前の確認で警告が出ます。学習自体は始められますが、
メモリ不足で失敗したり、非常に遅くなったりする可能性があります。


■ 推奨スペック
----------------------------------------------------------------
GPU       : NVIDIA の GPU で、VRAM 16GB 以上
メモリ    : 64GB
ディスク  : SSD に 100GB 以上の空き
            HDD でも動きますが、学習結果の保存やモデルの読み込みに時間がかかります。

かかった時間の例（VRAM 16GB の GPU の場合）：SDXL 系のキャラ LoRA（1600 ステップ）の学習が約 30 分、
比較画像の生成が約 5 分でした。素材や設定によって変わります。
GeForce GTX 10 シリーズ以前の GPU と、VRAM 12GB 未満の GPU での動作は確認していません。


■ 導入手順
----------------------------------------------------------------
1. 必要なソフトを入れる（入っていれば不要です）
   - Python は不要です。入っていない PC では、setup.bat がこのフォルダーの tools\ に
     専用の Python 3.11 を用意します（PC 全体にはインストールしません）。
   - Git も不要です。入っていない PC では、setup.bat が tools\git に専用の Git を用意します。
   - NVIDIA の GPU ドライバー : https://www.nvidia.com/ja-jp/drivers/
     バージョンが 570 より古い場合は更新してください。

2. zip を展開する
   展開先は、短いパスにしてください（例：D:\LoRAtelier）。
   パスが長すぎると、セットアップ中にファイルを作れずに失敗することがあります。
   展開先に十分な空き容量があることも確認してください。

3. setup.bat をダブルクリックする（初回だけ）
   学習エンジン、比較用の ComfyUI、必要なライブラリを自動で取得します。
   ダウンロードは合計で約 10GB あり、回線によっては 30 分から 1 時間以上かかります。
   「セットアップが完了しました」と表示されたら、ウィンドウを閉じてください。
   途中で失敗した場合は、もう一度 setup.bat を実行すると、足りない部分だけをやり直します。

4. start.bat をダブルクリックする（2 回目以降はこれだけです）
   ブラウザーが開き、http://127.0.0.1:7865/ に画面が表示されます。
   この画面にはこの PC からしか接続できません。
   start.bat の黒いウィンドウは、使い終わるまで閉じないでください。閉じるとツールが終了します。

   同じネットワーク（家庭や職場の LAN）の他の PC からも使いたいときは、start.bat の代わりに
   start_intranet.bat をダブルクリックします。他の PC から開くアドレス（例: http://192.168.1.10:7865/）は、
   起動した黒いウィンドウに表示されます。
   パスワードはないので、同じネットワークにいる人は誰でも操作できます。信頼できるネットワークだけで使ってください。
   他の PC から開けないときは、Windows のファイアウォールで python.exe の通信（プライベート ネットワーク）を許可してください。
   学習や画像生成は起動した PC の GPU で動き、LoRA の書き出し先も起動した PC のフォルダーです。
   start.bat と同時には起動できません。切り替えるときは、起動中の黒いウィンドウを閉じてから起動してください。

5. ベースモデルを用意する（初回だけ）
   セットアップではモデルを取得しません。最初の画面の「標準モデルをダウンロード」を押すと、
   SDXL 系の 3 種（Illustrious-XL v2.0・Pony Diffusion V6 XL・SDXL 1.0 base、合計 約 21GB）を取得します。
   手元にモデルファイルがある場合は、ダウンロードせずに models\checkpoints に置くだけで使えます。
   Anima・Qwen-Image-2512・Qwen-Image-2.1・MOSS-Image などは、あとから画面右上の「設定」→「おすすめのモデル」や、Hugging Face・Civitai のリンク、ダウンロードしたファイルのドロップで
   追加できます。Qwen-Image-2.1 と MOSS-Image は試験導入中で、動作を確認していないため動かない可能性があります。
   モデルにはそれぞれ利用条件があります。ダウンロードする前に確認してください。

6. 素材解析用の AI モデルを取得する（初回だけ・自動）
   最初に画像を取り込んだとき、解析用の AI モデル（合計 約 15GB）を自動でダウンロードします。
   ダウンロード中も画像の一覧表示や編集はできます。


■ 使い方の流れ
----------------------------------------------------------------
1. ホーム画面で「キャラクター LoRA」か「スタイル LoRA」を選びます。
2. 素材の画面に画像を入れます。ドラッグ＆ドロップ、Ctrl+V での貼り付け、
   「画像を追加」「フォルダーから」のどれでも取り込めます。
   取り込むとすぐに確認が始まり、問題のありそうな画像には理由が表示されます。
   採用・除外の切り替え、切り抜き、説明文の編集は自動で保存され、Ctrl+Z で元に戻せます。
   除外は提案だけで、元の画像が削除されることはありません。
3. 「学習を開始」を押します。設定は自動で決まります。
   変更したい場合は、学習の画面の「詳細設定」から変えられます。
4. 結果の画面で比較画像を見て、良いものを選んで「書き出す」を押します。
   書き出したフォルダーには、LoRA 本体と使い方の説明が入っています。

さらに詳しい説明は README.md にあります。


■ うまくいかないとき
----------------------------------------------------------------
- setup.bat で「用意した git を起動できませんでした」と出る場合は、ウイルス対策ソフトが
  tools\git をブロックしていないか確認してから、もう一度実行してください。
- setup.bat で「uv を取得できませんでした」と出る場合は、ネットへの接続を確認してから
  もう一度実行してください。うまくいかない場合は Python 3.10 以降を入れてから実行しても構いません。
- 学習が失敗した場合は、学習の画面に原因と対処の案が表示されます。
  詳しい記録は data\projects\<プロジェクト>\runs\<番号>\logs\ にあります。
- 学習が極端に遅い場合は、VRAM が足りず、メインメモリで代用している可能性があります。
  詳細設定でバッチサイズを 1 にするか、解像度を下げてください。
- 画面の不具合は data\server_errors.log、解析の不具合は data\analysis_worker.log、
  比較画像の不具合は data\comfyui.log に記録されます。


■ データの場所とアンインストール
----------------------------------------------------------------
作ったプロジェクト、登録したモデルの情報、学習結果は、展開したフォルダーの data\ に保存されます。
ダウンロードしたベースモデルは models\ に保存されます。

アンインストールするときは、展開したフォルダーを丸ごと削除してください。
ただし、作った LoRA やプロジェクトも消えるので、必要なものは先に別の場所へコピーしてください。
次の 2 つのフォルダーにもダウンロードしたファイルが残ります。不要なら削除してください。
  - 素材解析用の AI モデル : C:\Users\<ユーザー名>\.cache\huggingface
    （ほかのソフトが同じ場所を使っている場合があるので、注意して削除してください）
  - セットアップ時のダウンロードの一時保存 : C:\Users\<ユーザー名>\AppData\Local\uv\cache
